# 📦 Fleet & Parcel Tracking Dashboard

A modern, responsive B2B logistics dashboard built with HTML5, Tailwind CSS, and Vanilla JavaScript. Features real-time interactive mapping, status filtering, and shipment details timeline.

## ✨ Key Features
- 📊 **Dynamic KPI Metrics:** Live updates on shipment status counters.
- 🔍 **Search & Filter:** Instant search by Tracking ID or Customer name, with status filtering.
- 🗺️ **Interactive Map Integration:** Integrated with Leaflet.js to pinpoint package locations.
- ⏱️ **Shipment Timeline:** Visual step-by-step progress tracking for every delivery.
- ➕ **Add Shipments:** Interactive form to introduce new packages dynamically.
- 📱 **Fully Responsive:** Seamless layout adjustments for desktop and mobile devices.

## 🛠️ Tech Stack
- **Structure:** HTML5 (RTL / Arabic support)
- **Styling:** Tailwind CSS (via CDN)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Maps:** Leaflet.js
